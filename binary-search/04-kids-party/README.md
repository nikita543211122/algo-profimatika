# Шаг 2 · D. Детский праздник

## Идея

- Бинпоиск по времени T.
- Цикл помощника: z шариков + отдых, длина L = z·t + y.
- cnt(T) = (T / L)·z + min(z, (T % L) / t).
- good(T): Σ cnt_i(T) ≥ m. left = −1 (при m = 0 ответ 0), right = 3·10⁶.
- Распределение: жадно даём каждому min(cnt_i(T), осталось) — в сумме ровно m.

## Запуск

```bash
g++ -O2 -std=c++20 solution.cpp -o solution && ./solution < input.txt
python3 solution.py < input.txt
```

## Пример

Вход:
```
1 2
2 1 1
1 1 2
```

Выход (подходит любое корректное распределение):
```
1
0 1
```
