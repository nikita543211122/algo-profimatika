# Шаг 2 · C. Очень лёгкая задача

## Идея

- Бинпоиск по времени t.
- Первую копию делает быстрый ксерокс за m = min(x, y), затем оба работают параллельно.
- good(t): t ≥ m и (t − m)/x + (t − m)/y ≥ n − 1.
- Границы: left = 0 (плохо), right = n · max(x, y) (точно хорошо). До 2·10⁹ — нужен long long.
- Монотонность: F…F T…T, ищем первую T, ответ right.

## Запуск

```bash
g++ -O2 -std=c++20 solution.cpp -o solution && ./solution < input.txt
python3 solution.py < input.txt
```

## Пример

Вход:
```
4 1 1
```

Выход:
```
3
```
