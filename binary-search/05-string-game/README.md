# Шаг 2 · F. Игра со строкой

## Идея

- Бинпоиск по k — сколько букв успеет вычеркнуть Петя.
- when[j] — на каком шаге вычеркивается буква t[j] (обратная перестановка, a − 1 из-за 1-индексации).
- ok(k): двумя указателями проверяем, что p — подпоследовательность живых букв (when[i] ≥ k). Жадно берём самое раннее совпадение.
- Монотонность: T…T F…F (больше вычеркнули — сложнее). left = 0 хорошо, right = |t| − |p| + 1 плохо. Ответ left.
- Сложность O(|t| log |t|).

## Запуск

```bash
g++ -O2 -std=c++20 solution.cpp -o solution && ./solution < input.txt
python3 solution.py < input.txt
```

## Пример

Вход:
```
ababcba
abb
5 3 4 1 7 6 2
```

Выход:
```
3
```
