# Двоичный поиск

Решения задач из курса [ITMO Academy: пилотный курс → Двоичный поиск](https://codeforces.com/edu/course/2/lesson/6) на Codeforces. Для каждой задачи есть реализация на C++ и на Python.

| # | Задача | Идея |
|---|--------|------|
| 1 | [Двоичный поиск](01-binary-search) | lower bound по отсортированному массиву |
| 2 | [Количество чисел на отрезке](02-count-on-segment) | сортировка + `upperBound(r) − lowerBound(l)` |
| 3 | [Очень лёгкая задача](03-very-easy-problem) | бинпоиск по ответу (время) |
| 4 | [Детский праздник](04-kids-party) | бинпоиск по времени + жадное распределение |
| 5 | [Игра со строкой](05-string-game) | бинпоиск по числу вычеркнутых букв + два указателя |
| 6 | [Студенческие советы](06-student-councils) | бинпоиск по ответу, проверка `Σ min(a[i], c) ≥ k·c` |

## Шаблон

```cpp
// инвариант: good(left) != good(right)
while (right - left > 1) {
    long long mid = (left + right) / 2;
    if (good(mid)) right = mid;  // хорошие справа: F…F T…T
    else left = mid;
}
// ответ — right (или left, если хорошие слева: T…T F…F)
```

Границы выбираются так, чтобы одна точно была «плохой», а другая точно «хорошей».
