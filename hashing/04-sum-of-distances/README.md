# 2615. Sum of Distances

Для каждого индекса посчитайте сумму расстояний до всех индексов с таким же значением. [Условие LeetCode](https://leetcode.com/problems/sum-of-distances/description/)

## Идея

- Собираем словарь «значение → список индексов». Индексы добавляются слева направо, поэтому список каждой группы уже отсортирован.
- Для позиции `p` вклад индексов слева равен `left_count * p - left_sum`, справа — `right_sum - right_count * p`.
- Сначала `right_sum` равна сумме группы. На каждом шаге вычитаем из неё `p`, считаем оба вклада и переносим `p` в `left_sum`.
- В среднем `O(n)` времени и `O(n)` памяти. В C++ суммы и произведения вычисляем в `long long`.

## Пример

`nums = [1, 3, 1, 1, 2]` → `[5, 0, 3, 4, 0]`. У индекса `2` одинаковое значение с индексами `0` и `3`, поэтому там ответ `2 + 1 = 3`.
