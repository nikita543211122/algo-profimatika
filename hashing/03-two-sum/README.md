# 1. Two Sum

Верните индексы двух разных элементов с суммой `target`. По условию решение единственное. [Условие LeetCode](https://leetcode.com/problems/two-sum/description/)

## Идея

- Для `nums[i]` ищем дополнение `target - nums[i]` в словаре «число → индекс».
- Сначала выполняем поиск, потом сохраняем текущий индекс. Поэтому найденный индекс всегда строго меньше `i`.
- В среднем `O(n)` времени и `O(u)` дополнительной памяти, где `u` — число различных значений.

## Пример

`nums = [3, 3]`, `target = 6` → `[0, 1]`. Первая тройка попадает в словарь, вторая находит её.
