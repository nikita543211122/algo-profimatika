# 466C. Number of Ways

Посчитайте разбиения массива на три непустые непрерывные части с равными суммами. [Условие Codeforces](https://codeforces.com/problemset/problem/466/C)

## Идея

- Если общая сумма делится на три, обозначим сумму одной части через `target`. Иначе ответ равен нулю.
- Для разрезов после `i` и `j` элементов нужны префиксы с суммами `target` и `2 * target`, причём `1 ≤ i < j < n`.
- Идём слева направо. Сначала, если текущий префикс подходит для второго разреза, добавляем число ранее найденных первых. Затем учитываем текущий префикс как возможный первый. При нулевой сумме этот порядок сохраняет строгое `i < j`.
- Время `O(n)`, память `O(n)` на входной массив. В C++ для сумм и ответа нужен `long long`.
