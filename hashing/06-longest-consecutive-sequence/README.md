# 128. Longest Consecutive Sequence

Найдите длину самой длинной цепочки целых чисел подряд среди значений массива. [Условие LeetCode](https://leetcode.com/problems/longest-consecutive-sequence/description/)

## Идея

- Собираем уникальные значения в множество.
- Начинаем цепочку из `x`, только если `x - 1` отсутствует. Затем проверяем `x + 1`, `x + 2` и так далее.
- У каждой цепочки одно начало. Внутренние циклы суммарно обходят каждое уникальное число не более одного раза.
- В среднем `O(n)` времени и `O(u)` памяти, где `u` — число различных значений.
