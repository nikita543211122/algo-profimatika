# 2799. Count Complete Subarrays in an Array

Посчитайте подмассивы, содержащие все различные значения массива. [Условие LeetCode](https://leetcode.com/problems/count-complete-subarrays-in-an-array/description/)

## Идея

- Сначала считаем `need` — число различных значений во всём массиве. Затем поддерживаем частоты в окне `[left, right]`.
- Когда окно впервые полное для текущего `left`, любой конец от `right` до `n - 1` подходит. Прибавляем `n - right` и сдвигаем `left`.
- Если частота ушедшего числа стала нулевой, удаляем ключ. Размер словаря равен числу различных значений в окне.
- Обе границы проходят массив один раз. В среднем `O(n)` времени и `O(u)` памяти, где `u` — число различных значений.
