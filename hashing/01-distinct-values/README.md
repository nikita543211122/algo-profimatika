# A. Distinct Values

Для каждого теста выведите различные числа массива в порядке возрастания. [Условие Codeforces](https://codeforces.com/group/MwZqR4Zf5z/contest/711077/problem/A)

## Идея

- В C++ вставляем числа в `set<int>`. Повторный ключ не добавляется, а обход идёт по возрастанию. Время `O(n log(u + 1))`, где `u` — число различных значений.
- В Python собираем `set`, затем сортируем его через `sorted`. Время в среднем `O(n + u log(u + 1))`.
- Контейнеры хранят `O(u)` значений. Python также буферизует вход целиком.
