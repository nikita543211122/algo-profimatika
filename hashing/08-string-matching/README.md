# 1753. String Matching

Посчитайте все вхождения шаблона в текст. Вхождения могут пересекаться. [Условие CSES](https://cses.fi/problemset/task/1753)

## Идея

1. Пусть `n` — длина текста, `m` — длина шаблона. Если `m > n`, ответ равен нулю.
2. Строим для текста массивы хэшей префиксов. В C++ также сохраняем степени основания. В Python вычисляем только нужную степень `base^m % mod`, так как длина всех окон равна `m`. Отдельно считаем хэш шаблона по той же формуле.
3. Перебираем начала от `0` до `n - m` включительно. Для каждого `i` за `O(1)` вычисляем хэш окна `[i, i + m)`.
4. При совпадении обеих компонент хэша увеличиваем ответ на единицу. Окно каждый раз сдвигается на один символ.

При вычислении хэша `[l, r)` переменная `removed` хранит вклад первых `l` символов. В `prefix[r]` этот вклад сдвинут на `r - l` позиций. Например, при основании 10 для окна `[2, 5)` в строке цифр `12345` вычитаем `12 * 10³` и получаем `345`.

Время `O(n + m)`, дополнительная память `O(n)`. Используем два простых модуля и случайные основания. Двойное хэширование снижает вероятность ложного совпадения, но допускает коллизии.

## Пример

Вход

```text

```

```text

```
